# Superpowers plugin

This repo vendors [obra/superpowers](https://github.com/obra/superpowers) skills so **Cloud Agents** get the same TDD / debugging / planning workflows.

- Skills live in `.cursor/skills/`
- Session bootstrap runs via `.cursor/hooks.json`

**On your desktop Cursor**, also install the marketplace plugin for the fullest experience:

```text
/add-plugin superpowers
```
