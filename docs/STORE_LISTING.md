## Full description

VFD Hub is a professional mobile companion for variable frequency drive (VFD) commissioning and maintenance.

**Configure drives**
- Multi-vendor catalog: vendor, model, power, voltage
- Parameter reference and configuration workflow
- Save and restore named projects

**Tools for the field**
- Smart search across vendors and models
- Fault code lookup by manufacturer
- QR scan and generate for nameplate configs
- Motor calculators, unit converter, cable sizing, and more
- PDF manual import and viewer
- Compare up to three VFD models

**Built for industrial use**
- Works offline with on-device database
- Guest mode or local account
- Light and dark theme
- Multiple languages

Permissions are used only when you use the feature: camera (QR scan), microphone (optional voice commands), storage (manuals/drawings).

VFD Hub does not sell your data. Account and project data stay on your device unless you export or share files yourself.
