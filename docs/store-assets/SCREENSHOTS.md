# Phone screenshots for Play Store

Minimum **2** phone screenshots required. Recommended **6–8** showing main value.

## Quick capture (Android emulator)

1. Start emulator and install release or debug build.
2. Open each screen below, then run `capture_screenshots.bat` (or `adb exec-out screencap -p > file.png`).
3. Save PNGs into `docs/store-assets/screenshots/`.

## Suggested screens

| # | Screen | How to reach |
|---|--------|----------------|
| 1 | Welcome | Fresh install |
| 2 | Home / Configure | Guest login → Configure tab |
| 3 | VFD selection | Pick vendor + model |
| 4 | Tools hub | Tools tab |
| 5 | Fault codes | Tools → Fault codes |
| 6 | QR scan | Tools → Scan QR |
| 7 | Projects | Projects tab |
| 8 | Dark theme | Account → toggle theme |

Use **1080×1920** or higher portrait PNG. Crop status bar if you prefer a cleaner look.

## Play Console

**Main store listing** → **Phone screenshots** → upload PNGs from `docs/store-assets/screenshots/`.
